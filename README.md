## Description
This repository contains the solutions for Lab 4b, covering structured JSON data (`books.json`), retrieving and displaying JSON via the native `fetch()` API (`books.html`), and jQuery 4.0.0 DOM manipulation and event handling (`jquery-dom.html`).

## Setup and Instructions to Run
1. Download or clone this repository and open the folder in Visual Studio Code.
2. Install the **Live Server** extension in VS Code.
3. Right-click `books.html` and select **Open with Live Server** (do not open via `file://`, as `fetch()` requires an HTTP server).
4. Open `jquery-dom.html` in a modern browser (with internet access for the jQuery 4.0.0 CDN) and click the button to test the alert.
